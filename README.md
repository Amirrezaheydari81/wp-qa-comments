# پرسش و پاسخ (WP Q&A Comments)

**نسخه:** 1.1.0  
**نویسنده:** Amirreza Heydari  
**آدرس:** [clarotm.ir](https://clarotm.ir)

افزونه سبک وردپرس برای سیستم **سؤال و پاسخ** روی نوشته‌ها، برگه‌ها و CPTها.

درون‌ریزی JSON برای محتوای **دمو / تست / Seed** است و نباید به‌عنوان نظر واقعی کاربران معرفی شود.

---

## ویژگی‌ها

- فرم فرانت‌اند ساده (فقط نام + سؤال — بدون ایمیل)
- پاسخ جداگانه با نام، سمت، لینک و عکس پروفایل که از پیشخوان ست می‌شود
- نمایش روی نوشته، برگه، یا هر دو
- منوی مدیریت: لیست، تأیید، رد، ویرایش، پاسخ، حذف، عملیات گروهی
- درون‌ریزی JSON سراسری + متاباکس روی صفحه ویرایش نوشته/برگه
- شورت‌کد `[wpqa_comments]`
- AJAX با Vanilla JS (بدون jQuery)
- Load More
- کپچای تصویری سبک و نویزدار + honeypot (اختیاری: ریاضی / Cloudflare Turnstile)
- کپچا فقط وقتی فرم به محدوده دید برسد ساخته می‌شود
- مخفی‌سازی کامل باکس وقتی سؤال تأییدشده‌ای وجود ندارد
- تاریخ شمسی (جلالی)
- CSS ایزوله زیر `.wpqa-wrap`، خوانا روی پس‌زمینه `#0A3333`
- RTL و رابط فارسی
- جدول اختصاصی با `dbDelta`

---

## نیازمندی‌ها

- WordPress 5.8+
- PHP 7.4+
- برای کپچای تصویری: افزونه GD با پشتیبانی `imagejpeg` (در غیر این صورت به کپچای ریاضی برمی‌گردد)

---

## نصب

1. پوشه `wp-qa-comments` را در `wp-content/plugins/` قرار دهید.
2. افزونه را فعال کنید.
3. منوی **پرسش و پاسخ** در پیشخوان ظاهر می‌شود.

## استفاده

### نمایش خودکار

از **پرسش و پاسخ → تنظیمات**:

### پاسخ‌دهنده

بالای صفحه تنظیمات:

| فیلد | اثر در سایت |
|------|-------------|
| نام پاسخ‌دهنده | بالای هر پاسخ. اگر خالی باشد: «پاسخ مدیر سایت» |
| عکس پروفایل | دکمه **انتخاب از رسانه**. تصویر از کتابخانه رسانه وردپرس است |
| سمت | زیر نام، اختیاری |
| لینک پروفایل | نام را لینک می‌کند، اختیاری |

بعد از ذخیره، همان نام و عکس روی همه پاسخ‌های تأییدشده دیده می‌شود. آدرس تصویر هنگام ذخیره نگه داشته می‌شود تا در هر بازدید به کتابخانه رسانه مراجعه نشود.

### نمایش

- فقط نوشته‌ها، فقط برگه‌ها، یا هر دو
- تعداد سؤال در هر صفحه
- نیاز به تأیید مدیر
- نمایش فرم
- نمایش خودکار در انتهای محتوا
- تنظیمات کپچا

اگر هیچ سؤال `approved` نباشد، کادر اصلاً رندر نمی‌شود. تعداد تأییدشده‌ها در متای `_wpqa_approved_count` همان نوشته ذخیره می‌شود و با ثبت، تأیید، رد یا حذف به‌روز می‌گردد.

### شورت‌کد

```text
[wpqa_comments]
```

```text
[wpqa_comments post_id="123"]
```

## کپچا و ضد اسپم

مسیر: **پرسش و پاسخ → تنظیمات**

| نوع | توضیح |
|-----|--------|
| تصویری (پیش‌فرض) | JPEG کوچک با نویز سبک، ۴ کاراکتر، دکمه تازه‌سازی با آیکون |
| ریاضی | جمع ساده (Fallback) |
| Turnstile | نیاز به Site Key و Secret Key کلودفلر |

همیشه یک فیلد **honeypot** مخفی هم فعال است.

کپچای تصویری و ریاضی در HTML اولیه ساخته نمی‌شوند. اسکریپت فرانت وقتی فرم نزدیک دید قرار گرفت یک‌بار `wpqa_refresh_captcha` را صدا می‌زند.

نکات بهینه‌سازی کپچای تصویری:

- تصویر کوچک (`150×48`)
- خروجی JPEG فشرده
- بدون TTF (فونت داخلی GD)
- نویز محدود برای مصرف کم CPU
- بدون نوشتن transient در رندر صفحه

## درون‌ریزی JSON

### سراسری

**پرسش و پاسخ → درون‌ریزی JSON**

```json
[
  {
    "post_id": 123,
    "name": "علی",
    "question": "این محصول برای استفاده روزمره مناسبه؟",
    "answer": "بله، برای استفاده روزمره کاملاً مناسبه."
  },
  {
    "post_id": 123,
    "name": "سارا",
    "question": "ضمانت محصول چطوره؟"
  }
]
```

### روی همان نوشته/برگه

متاباکس **پرسش و پاسخ — درون‌ریزی JSON** در صفحه ویرایش:

```json
[
  {
    "name": "علی",
    "question": "این محصول برای استفاده روزمره مناسبه؟",
    "answer": "بله، برای استفاده روزمره کاملاً مناسبه."
  }
]
```

`post_id` لازم نیست؛ همه آیتم‌ها به همان نوشته وصل می‌شوند.

گزینه‌ها:

- وضعیت پیش‌فرض
- تولید تاریخ‌های تصادفی (دمو/تست)

#### قانون تاریخ تصادفی

- بین تاریخ انتشار نوشته و الان
- هرگز از تاریخ انتشار نوشته عقب‌تر نیست
- پاسخ مدیر بعد از سؤال و نه بعد از الان

نمونه: [`sample-import.json`](sample-import.json)

## دیتابیس

جدول: `{prefix}wpqa_comments`

| ستون | توضیح |
|------|--------|
| `id` | شناسه |
| `post_id` | نوشته مرتبط |
| `name` | نام |
| `question` | سؤال |
| `answer` | پاسخ مدیر |
| `status` | وضعیت |
| `created_at` | زمان ایجاد |
| `replied_at` | زمان پاسخ |

ایندکس‌ها: `post_id`، `status`، `created_at`، و ترکیبی `post_id + status`.

لیست فرانت فقط ستون‌های `id`، `name`، `question`، `answer` و `created_at` را می‌خواند و شمارش جداگانه نمی‌زند؛ تعداد از متای کش‌شده می‌آید.

## فرانت‌اند و قالب

- استایل‌ها فقط زیر کلاس `.wpqa-wrap` هستند
- فونت از قالب به ارث می‌رسد؛ افزونه فونت جدا لود نمی‌کند
- رنگ متن و کادر برای پس‌زمینه `#0A3333` تنظیم شده است
- پروفایل پاسخ: `.wpqa-answer-profile`، `.wpqa-answer-avatar`، `.wpqa-answer-label`، `.wpqa-answer-role`
- هدف: کمترین تداخل با قالب و صفحه‌سازها (مثل Elementor)

---

## کارایی

- تنظیمات در هر درخواست یک‌بار از `get_option` خوانده می‌شود
- تعداد سؤال تأییدشده در post meta کش می‌شود
- کوئری فرانت `COUNT(*)` جدا ندارد و `SELECT *` نمی‌زند
- عکس پاسخ‌دهنده با URL ذخیره‌شده چاپ می‌شود
- کپچا تا نزدیک شدن فرم به دید، transient و تصویر نمی‌سازد

## حذف افزونه

اگر در تنظیمات گزینه پاک‌سازی فعال باشد، هنگام حذف کامل افزونه جدول، تنظیمات و متای `_wpqa_approved_count` پاک می‌شوند.  
غیرفعال‌سازی به‌تنهایی داده را حذف نمی‌کند.
