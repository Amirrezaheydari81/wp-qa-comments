# پرسش و پاسخ (WP Q&A Comments)

افزونه سبک وردپرس برای نمایش سیستم **سؤال و پاسخ** در نوشته‌ها، برگه‌ها و انواع محتوای سفارشی.

درون‌ریزی JSON برای محتوای **دمو / تست / Seed** طراحی شده است و نباید به‌عنوان نظر واقعی کاربران معرفی شود.

---

## ویژگی‌ها

- فرم ساده فرانت‌اند (فقط نام + سؤال — بدون ایمیل)
- پاسخ جداگانه مدیر با ظاهر متمایز
- منوی مدیریت: لیست، تأیید، رد، ویرایش، پاسخ، حذف
- درون‌ریزی JSON سراسری و **متاباکس درون‌ریزی روی صفحه ویرایش نوشته/برگه**
- شورت‌کد `[wpqa_comments]`
- AJAX بدون jQuery
- صفحه‌بندی / Load More
- RTL و رابط فارسی
- نمایش تاریخ شمسی (جلالی)
- جدول اختصاصی با `dbDelta`

---

## نصب

1. پوشه `wp-qa-comments` را در مسیر `wp-content/plugins/` قرار دهید.
2. از **افزونه‌ها**، افزونه را **فعال** کنید.
3. منوی **پرسش و پاسخ** در پیشخوان ظاهر می‌شود.

حداقل نیاز:

- WordPress 5.8+
- PHP 7.4+

---

## استفاده سریع

### نمایش خودکار

در **پرسش و پاسخ → تنظیمات**:

- انواع محتوا (نوشته، برگه، CPT)
- تعداد سؤال در هر صفحه
- نیاز به تأیید مدیر
- نمایش فرم
- نمایش خودکار در انتهای محتوا

### شورت‌کد

```text
[wpqa_comments]
```

روی نوشته/برگه فعلی:

```text
[wpqa_comments post_id="123"]
```

## درون‌ریزی JSON

### الف) سراسری

مسیر: **پرسش و پاسخ → درون‌ریزی JSON**

فرمت:

```json
[
  {
    "post_id": 123,
    "name": "علی",
    "question": "این محصول برای استفاده روزمره مناسبه؟",
    "answer": "بله، برای استفاده روزمره کاملاً مناسبه."
  },
  {
    "post_id": 123,
    "name": "سارا",
    "question": "ضمانت محصول چطوره؟"
  }
]
```

### ب) روی همان نوشته/برگه

در صفحه ویرایش نوشته، باکس **پرسش و پاسخ — درون‌ریزی JSON**:

- نیازی به `post_id` نیست؛ همه آیتم‌ها به همان نوشته وصل می‌شوند.

```json
[
  {
    "name": "علی",
    "question": "این محصول برای استفاده روزمره مناسبه؟",
    "answer": "بله، برای استفاده روزمره کاملاً مناسبه."
  }
]
```

گزینه‌های مفید:

- وضعیت پیش‌فرض (`approved` / `pending` / `rejected`)
- تولید تاریخ‌های تصادفی (فقط برای دمو/تست)

#### قانون تاریخ تصادفی

اگر «تولید تاریخ‌های تصادفی» فعال باشد:

- تاریخ سؤال بین `تاریخ انتشار نوشته` و `الان` انتخاب می‌شود (داخل بازهٔ روزهای تنظیم‌شده)
- تاریخ سؤال **هرگز از تاریخ انتشار نوشته عقب‌تر نیست**
- تاریخ پاسخ مدیر بعد از تاریخ سؤال است و از «الان» جلوتر نمی‌رود

نمونه فایل: [`sample-import.json`](sample-import.json)

## وضعیت‌ها

| وضعیت     | توضیح                          |
|-----------|--------------------------------|
| `pending` | در انتظار تأیید                |
| `approved`| تأیید شده (فقط این‌ها در سایت) |
| `rejected`| رد شده                         |

## دیتابیس

جدول: `{prefix}wpqa_comments`

| ستون        | توضیح              |
|-------------|--------------------|
| `id`        | شناسه              |
| `post_id`   | نوشته مرتبط        |
| `name`      | نام کاربر          |
| `question`  | متن سؤال           |
| `answer`    | پاسخ مدیر          |
| `status`    | وضعیت              |
| `created_at`| زمان ایجاد         |
| `replied_at`| زمان پاسخ مدیر     |

## حذف افزونه

در تنظیمات می‌توانید فعال کنید که هنگام **حذف کامل** افزونه، جدول و تنظیمات هم پاک شوند.  
غیرفعال‌سازی به‌تنهایی داده‌ها را حذف نمی‌کند.

## امنیت
